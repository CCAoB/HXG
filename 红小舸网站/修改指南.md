# 红小舸官网 - 修改指南

> 本文档详细说明如何修改网站中的文字、图片、数据、配色等内容。
> 无需编程基础，按照步骤操作即可。

---

## 📁 一、项目文件结构

```
红小舸官网/
├── index.html          # 主页面（所有文字内容都在这里）
├── css/
│   └── style.css       # 样式文件（配色、字体、动画、布局）
├── js/
│   └── main.js         # 交互脚本（动画、计数、菜单等）
├── assets/
│   └── images/         # 所有图片存放处
│       ├── ip.png    # 学校校徽
│       └── ip.png      # 红小舸IP形象
└── 修改指南.md          # 本文档
```

**核心原则**：
- 改**文字内容** → 编辑 `index.html`
- 改**颜色/字体/间距** → 编辑 `css/style.css`
- 改**图片** → 替换 `assets/images/` 里的文件
- 改**动画/交互** → 编辑 `js/main.js`

## 🖼️ 三、图片修改

### 3.1 现有图片替换

| 图片 | 文件名 | 建议尺寸 | 格式 |
|------|--------|---------|------|
| 学校校徽 | `assets/images/ip.png` | 高度≥100px，透明背景 | PNG |
| 红小舸IP | `assets/images/ip.png` | 建议 800×800px，透明背景 | PNG |

**替换方法**：
1. 准备好新图片，重命名为对应文件名（如 `ip.png`）
2. 复制到 `assets/images/` 文件夹，覆盖原文件
3. 刷新浏览器即可看到效果

### 3.2 新增照片墙图片

目前照片墙使用渐变色占位，替换为真实图片步骤：

1. 将图片放入 `assets/images/`，命名如 `photo1.jpg`
2. 打开 `index.html`，搜索 `gallery-item`
3. 找到对应格子，将：
   ```html
   <div class="gallery-item reveal tall" style="background: linear-gradient(...)">
   ```
   改为：
   ```html
   <div class="gallery-item reveal tall" style="background: url('./assets/images/photo1.jpg') center/cover;">
   ```

**照片墙布局说明**：
- `tall` 类 = 占2行高度（竖图）
- `wide` 类 = 占2列宽度（横图）
- 普通 = 1×1 方格
- 建议图片尺寸：横图 16:9，竖图 3:4，方图 1:1

### 3.3 新增视频封面图

1. 将封面图放入 `assets/images/`，命名如 `video1.jpg`
2. 搜索 `video-thumb`，将：
   ```html
   <div class="video-thumb" style="background: linear-gradient(...)">
   ```
   改为：
   ```html
   <div class="video-thumb" style="background: url('./assets/images/video1.jpg') center/cover;">
   ```
3. 建议尺寸：1280×720px（16:9）

### 3.4 新增文创产品图

1. 将产品图放入 `assets/images/`，命名如 `product1.jpg`
2. 搜索 `culture-img`，将：
   ```html
   <div class="culture-img" style="background: linear-gradient(...)">
   ```
   改为：
   ```html
   <div class="culture-img" style="background: url('./assets/images/product1.jpg') center/cover;">
   ```
3. 同时删除该格子内的 `<div class="culture-placeholder">...</div>`
4. 建议尺寸：800×800px（正方形）

### 3.5 团队成员头像

目前使用字母占位，替换为真实头像：

1. 将头像放入 `assets/images/`，命名如 `member1.jpg`
2. 搜索 `team-avatar`，将：
   ```html
   <div class="team-avatar" style="background: linear-gradient(...)">
       <span>队</span>
   </div>
   ```
   改为：
   ```html
   <div class="team-avatar" style="background: url('./assets/images/member1.jpg') center/cover;"></div>
   ```
3. 建议尺寸：400×400px（正方形）

### 图片优化建议
- 所有图片建议压缩后再上传，推荐工具：[TinyPNG](https://tinypng.com/)（免费在线压缩）
- 单张图片建议控制在 500KB 以内
- 照片墙大图不超过 1MB
- 格式优先：图标/Logo 用 PNG，照片/封面用 JPG/WebP

## 📊 四、数据修改

### 4.1 首屏统计数字

在 `index.html` 中搜索 `hero-stats`，找到：
```html
<span class="stat-num" data-target="15">0</span>
```

共4个：实践天数、调研地点、采访人物、产出作品。

```html
<span class="data-num" data-target="8">0</span>
<span class="data-unit">篇</span>
```
- 修改 `data-target` 的值 = 改数字
- 修改 `data-unit` 的内容 = 改单位（篇/部/张/件等）

### 4.3 时间线年份

搜索 `timeline-year`，直接修改年份数字即可。

## 🎨 五、配色修改

所有颜色定义在 `css/style.css` 最顶部的 `:root` 变量中：

```css
:root {
    --sea-blue: #4A90B8;        /* 海浪蓝（主色） */
    --sea-light: #6BB3D9;       /* 浅海蓝 */
    --sea-lighter: #8ECAE6;     /* 更浅的蓝 */
    --deep-green: #1B4332;      /* 墨绿（主色） */
    --green-mid: #2D6A4F;       /* 中绿 */
    --green-light: #40916C;     /* 浅绿 */
    --china-red: #C1121F;       /* 中国红（点缀） */
    --red-light: #E63946;       /* 浅红 */
    --gold: #D4A574;            /* 金色（强调） */
    --gold-light: #E8C99B;      /* 浅金 */
    --bg-cream: #F8F5F0;        /* 米白背景 */
    --bg-blue: #E8F0F4;         /* 浅蓝背景 */
}
```

**修改方法**：直接替换对应的十六进制颜色值，全站自动生效。

**常用配色参考**：
- 想更蓝：将 `--deep-green` 改为 `#1A5276`
- 想更红：将 `--sea-blue` 改为 `#B91C1C`
- 想更暖：将 `--bg-cream` 改为 `#FEF3E2`

## 🔤 六、字体修改

字体同样在 `css/style.css` 的 `:root` 中定义：

```css
--font-brush: 'Ma Shan Zheng', cursive;     /* 书法字体（标题） */
--font-title: 'ZCOOL XiaoWei', serif;       /* 标题字体 */
--font-body: 'Noto Sans SC', sans-serif;    /* 正文字体 */
```

目前使用 Google Fonts 在线字体，在 `index.html` 头部已引入：
```html
<link href="https://fonts.googleapis.com/css2?family=Ma+Shan+Zheng&family=ZCOOL+XiaoWei&family=Noto+Sans+SC:wght@300;400;500;700&display=swap" rel="stylesheet">
```

**更换字体**：
1. 去 [Google Fonts](https://fonts.google.com/) 选择喜欢的中文字体
2. 复制字体链接替换 index.html 中的 link
3. 修改 css/style.css 中对应的字体变量名

**推荐中文字体**：
- 书法体：Ma Shan Zheng（马善政）、ZCOOL KuaiLe（站酷快乐体）
- 标题体：ZCOOL XiaoWei（站酷小薇）、Noto Serif SC（思源宋体）
- 正文体：Noto Sans SC（思源黑体）

## 🚀 七、部署上线

### 方式一：微信公众号网页托管（推荐）

1. 将整个 `红小舸官网` 文件夹打包为 zip
2. 登录微信公众平台 → 公众号网页
3. 上传 zip 压缩包
4. 等待部署完成，获取访问链接

### 方式二：本地预览

1. 双击 `index.html` 即可在浏览器打开
2. 或使用 VS Code 的 Live Server 插件预览

### 方式三：免费静态托管

- **Cloudflare Pages**：免费，全球CDN，无需备案
- **Vercel**：免费，部署简单
- **Netlify**：免费，拖拽上传

### 方式四：自有服务器

1. 购买域名 + 云服务器（阿里云/腾讯云学生机）
2. 域名完成 ICP 备案
3. 将文件上传服务器，配置 Nginx 指向 index.html

## ❓ 八、常见问题

### Q1: 替换图片后不显示？
- 检查文件名是否完全一致（大小写敏感）
- 检查路径是否正确（必须是 `./assets/images/xxx.jpg`）
- 检查图片格式是否正确

### Q2: 手机端显示错乱？
- 网站已做响应式适配，如遇问题检查是否修改了 css 中的 media query
- 确保 viewport meta 标签存在（index.html 第5行）

### Q3: 字体加载不出来？
- Google Fonts 在国内可能加载较慢，可更换为国内字体CDN
- 或删除字体链接，使用系统默认字体

### Q4: 如何添加新的功能模块？
1. 在 index.html 中对应位置复制一个现有模块的 HTML 结构
2. 修改内容和 id
3. 在导航栏添加对应链接
4. 如需特殊样式，在 css/style.css 中添加

### Q5: 视频怎么播放？
- 目前视频卡片是展示用，点击无实际播放
- 如需播放，可将视频上传到腾讯视频/B站，获取嵌入代码
- 或在 js/main.js 中添加播放逻辑

### Q6: 打包时要注意什么？
- 入口文件必须命名为 `index.html`
- 所有路径使用相对路径（./开头）
- 不要包含中文路径以外的特殊字符
- 打包整个文件夹，不要只打包单个文件
